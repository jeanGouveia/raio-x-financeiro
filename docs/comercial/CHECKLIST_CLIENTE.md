# Checklist Cliente — Site Express

## Checklist de informações

- [ ] Nome comercial do negócio
- [ ] Logo (arquivo em formato PNG, SVG ou similar)
- [ ] WhatsApp principal
- [ ] Telefone adicional, se houver
- [ ] Instagram
- [ ] Facebook
- [ ] Outras redes sociais
- [ ] Endereço completo
- [ ] Horário de funcionamento
- [ ] Descrição do negócio
- [ ] Serviços/produtos principais
- [ ] Fotos do negócio/produtos
- [ ] Cores preferidas (códigos hex se disponível)
- [ ] Domínio (se já possui)
- [ ] Sites de referência (gostos/desgostos)

## Checklist de aprovação

- [ ] Conteúdo aprovado pelo cliente
- [ ] Layout aprovado pelo cliente
- [ ] WhatsApp testado e funcionando
- [ ] Links validados
- [ ] Mobile testado (360px, 390px, tablet)
- [ ] Desktop testado (1024px, 1440px)
- [ ] Endereço/mapa validado
- [ ] Redes sociais abrindo corretamente
- [ ] SEO básico configurado (title, meta description)
- [ ] Console sem erros críticos
- [ ] Performance básica aceitável
- [ ] Deploy realizado
- [ ] HTTPS funcionando
- [ ] Cliente validou em produção
- [ ] Entrega formal concluída

## Notas

- Marcar cada item conforme for coletado/testado.
- Antes de iniciar a implementação, garantir que o cliente forneceu pelo menos o essencial (nome, telefone, descrição básica).
- A rodada de ajustes incluída deve ser usada preferencialmente para refinamentos finais, não para mudanças estruturais.
