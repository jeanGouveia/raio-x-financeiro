# Qualificação de Lead — Site Express

## Perguntas de qualificação

1. Qual é o nome do negócio?
2. O que você vende ou qual serviço presta?
3. Já possui site?
4. Possui Instagram/Facebook?
5. Qual é o principal objetivo do site?
6. Quais informações precisam aparecer?
7. Possui logo?
8. Possui fotos próprias?
9. Possui domínio?
10. Existe alguma funcionalidade além de apresentar a empresa e facilitar contato?

## Regras de classificação

### Cabe no Site Express

Quando a necessidade for essencialmente:
- Presença digital de uma página
- Recursos simples de apresentação
- Facilitar contato via WhatsApp/telefone
- Informações básicas sobre o negócio
- Localização e horário de funcionamento

### Precisa de orçamento personalizado

Quando houver:
- Login/área restrita
- Painel administrativo
- Pagamento online
- Catálogo complexo
- E-commerce
- Agendamento online
- Integração com sistemas externos
- Banco de dados complexo
- Múltiplas páginas relevantes
- Automações
- Regras de negócio específicas
- Formulários avançados
- Upload/download de arquivos
- Área de cliente

## Notas

- Se o cliente não souber responder claramente, usar a seção "Você não precisa saber qual sistema precisa" da home para ajudar a entender a necessidade real.
- Quando houver dúvida, prefira orçamento personalizado a forçar no Site Express.
