# Processo de Entrega — Site Express

## 1. Recebimento

- Coletar briefing do cliente (usar template BRIEFING_SITE_EXPRESS.md)
- Qualificar se cabe no Site Express (usar QUALIFICACAO_LEAD.md)
- Confirmar escopo com cliente

## 2. Escopo

- Confirmar que a necessidade cabe no Site Express
- Alinhar expectativas sobre o que está incluído
- Documentar o que NÃO está incluído
- Confirmar 1 rodada de ajustes

## 3. Conteúdo

- Organizar material fornecido pelo cliente
- Validar que informações essenciais foram recebidas
- Solicitar complementos se necessário
- Adaptar copy para web quando apropriado (sem inventar conteúdo)

## 4. Implementação

- Construir a página utilizando estrutura reutilizável quando adequado
- Respeitar escopo de até 5 seções
- Aplicar identidade visual fornecida ou usar design neutro/profissional
- Integrar WhatsApp, redes sociais e localização
- Configurar SEO básico

## 5. QA (Quality Assurance)

Testar em:

- Mobile: 360px, 390px
- Tablet: 768px
- Desktop: 1024px, 1440px

Validar:

- WhatsApp funcionando
- Links válidos
- Endereço/mapa correto
- Redes sociais abrindo
- Responsividade
- Console sem erros críticos
- Performance básica aceitável
- SEO básico (title, meta description)

## 6. Revisão do cliente

- Enviar link de preview
- Coletar feedback
- Aplicar ajustes (1 rodada incluída)
- Refinar conforme necessário dentro do escopo

## 7. Produção

- Publicar em ambiente de produção
- Configurar domínio (se fornecido pelo cliente)
- Configurar HTTPS
- Validar deploy

## 8. Validação final

- Verificar domínio funcionando
- Verificar HTTPS
- Testar mobile em produção
- Testar desktop em produção
- Validar CTAs
- Verificar SEO básico

## 9. Entrega

- Registrar versão final
- Enviar confirmação ao cliente
- Documentar handoff para manutenção
- Arquivar projeto
